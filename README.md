# maccydee.github.io

Personal link page for Callum McDonald, served by GitHub Pages at
**https://maccydee.github.io**

A single static `index.html`. No build step, no dependencies, no tracking.
Push to `main` and Pages redeploys.

- `index.html` is the live page.
- `concepts/` holds the alternate design directions that were not chosen.

## Editing

Everything lives in `index.html`: the design plan comment block at the top
records the palette, typefaces, layout concept and dark-mode tokens, so change
tokens rather than hardcoding colours in rules.
